# MERN E-Cart Starter

This archive contains a starter MERN application (backend + frontend) with:
- Login / Signup (JWT)
- Admin & User roles
- Product add (admin) and realtime product push via socket.io
- Cart add, user cart view, admin view all carts
- Frontend: Vite + React + Tailwind, Axios service layer
